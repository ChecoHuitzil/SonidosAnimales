# Sonidos de Animales

**Autor:** Sergio Jimenez Huitzil

App de Android que reproduce el sonido de cada animal al tocar su imagen.

- **Pantalla principal** (`MainActivity`): título, nombre del autor y dos botones, **GRANJA** y **SALVAJES**, que cambian el fragmento que se muestra en el contenedor.
- **GranjaFragment**: gallo, cerdo, oveja y caballo.
- **SalvajesFragment**: elefante, rana y lobo.
- Los sonidos se reproducen con `MediaPlayer` desde `res/raw`. Si tocas otro animal, el sonido anterior se detiene.
